# HD-Only v0.8.2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Remove the Classic presentation from every active browser/build path and ship a fail-closed HD-only game identified as `v0.8.2`.

**Architecture:** Make HD an invariant at the HTML shell, game UI, and renderer-controller layers. Leave historical Classic files and dead renderer source in the repository, but remove every reachable Classic asset request, preference/toggle, and fallback; filter Classic presentation files from Pages output and prove the result with static, unit, build, and browser request tests.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Node `node:test`, Playwright-backed repository browser verification, Cloudflare Pages build script.
