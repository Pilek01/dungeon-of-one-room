# Room object and milestone Warden redesign prompts

Generation mode: built-in Codex ImageGen (`image_gen`). Generated sources use a
flat `#ff00ff` chroma-key background and are normalized by the repository's
pinned asset pipeline.

## Active shrine

Create a production-ready pixel-art game sprite redesign of the existing active
shrine for a dark gothic top-down dungeon. Preserve its cyan and violet magical
identity, but make it visibly three-dimensional and physically grounded: a broad
stepped stone plinth in 3/4 top-down perspective, thick front lip, readable side
faces, a recessed central dais, short side buttresses, and a substantial rear
gothic arch holding a glowing violet crystal. The shrine must feel like one
connected architectural object, fit a 2x2 tile footprint, use a 55–60 degree
top-down camera, remain centered and fully visible, and contain no floor, text,
characters, detached shadows, or particles outside its silhouette. Use a flat
solid `#ff00ff` background.

## Inactive shrine

Create the inactive state of exactly the same shrine. Preserve architecture,
camera, proportions, plinth, arch, buttresses, crystals, alignment, and
silhouette. Turn off the magic: dark desaturated amethyst core, dim carved teal
grooves, unlit small crystals, no aura or particles. Keep the structure readable
through stone depth and highlights. Use a flat solid `#ff00ff` background.

## Descent Warden palette reference

Create a production-ready HD pixel-art milestone Warden reference for a gothic
top-down action roguelite: ancient compact armored sentinel, broad grounded
stance, heavy charcoal stone-and-steel plate, restrained antique-gold trim,
sealed helmet and cyan eye/core. Show exactly three separated full-body idle
frames left-to-right (neutral, compressed/dim, raised/bright), identical scale
and baseline, in 3/4 top-down view. No floor, shadows, effects, text, or extra
figures. Use a flat solid `#ff00ff` background.

## Corruption Warden palette reference

Create the Corruption variant of the same three-frame Warden reference,
preserving identity, poses, scale, camera, layout, baseline, and silhouette.
Use tarnished black-green steel, ancient dark bronze, close-fitting root growths,
moss, a toxic teal-green eye/core, and narrow sickly green fissures. Keep it an
armored sentinel rather than a plant monster. Use a flat solid `#ff00ff`
background.

## Abyss Warden palette reference

Create the Abyss variant of the same three-frame Warden reference, preserving
identity, poses, scale, camera, layout, baseline, and silhouette. Use matte
obsidian and near-black violet armor, integrated void-crystal inserts, cold
silver edges, a violet-magenta eye/core, and restrained purple fissures. Keep
all crystals close to the solid armored silhouette. Use a flat solid `#ff00ff`
background.
